# Docker Setup
1. Cài đặt Docker Desktop hoặc Docker Engine.
2. Đảm bảo docker daemon đang chạy bằng lệnh `docker info`.
3. (Tùy chọn) Thêm user vào group docker trên Linux để không cần dùng sudo.
